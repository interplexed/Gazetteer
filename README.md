# Gazetteer: Data For Exploring The World

>[!NOTE]
> This was submitted for a project in 2024, with only some minor improvements added since.

## Description
A suitable definition of 'gazetteer' is found on [Wikipedia](https://en.wikipedia.org/wiki/Gazetteer):
> A gazetteer is a geographical dictionary or directory used in conjunction with a map or atlas. 
> It typically contains information concerning the geographical makeup, social statistics and physical features of a country, region, or continent.

The [Gazetteer](https://lewiscooper.dev/gazetteer) webapp aims to deliver the most essential globetrotting info right to your armchair.  
By using the country selection list in the menu, you can easily find transport, culture, and activities for anywhere in the world.  
See the buttons on the left of the map for different information sources, and on the right there is a layer selection button for the map tiling options and place marker categories.  
 
## Project Objectives
### Build A Country Profile App
* Use Leaflet.js in combination with map tile providers
* Pull data about geolocations from third party API sources
* Use map layering to display GeoJSON geometry and map markers
* Implement a front-end framework such as Bootstrap

### User Experience
* Ensure the app functions well on small portable devices like mobile phones
* Produce an attractive layout using custom Leaflet markers and CSS
* Source interesting and useful data about the country
